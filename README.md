🚀 Installation method
Method One of Three:Restablishing Manually

    Download front Github (this repo)

    ComfyUI-PainterNodes-MiniMax-Qwen2.1 folder is unpacked into the custom_nodes directory of ConfyUI:

    ComfyUI/
    └── custom_nodes/
        └── ComfyUI-PainterNodes-MiniMax-Qwen2.1/
          

    Installation Dependency:

The original repo recommends soundfile>=0.12.1 and numpy>=1.21.0 which are available in most ComfyUI installations.
