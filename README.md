This package is a limited extract of ComfyUI-PainterNodes by Painter Boy. This repo focuses on the Minimax-H3 and Qwen 2.1 related PainterNodes only.
==================================================================

List of nodes included in this limited extract:

- PainterFLF2V
- PainterMinimaxH3LatentUpscaler
- painterMiniMaxRefToVideo
- PainterMiniMaxReftoVideo2
- PainterMiniMaxReftoVideo3
- PainterMiniMaxReftoVideo6
- PainterQwenImage21
- PainterSigmasGraph
- PainterSizeSettings
- PainterVRAM

==================================================================
🚀 Installation method

    Download front Github (this repo)

    ComfyUI-PainterNodes-MiniMax-Qwen2.1 folder is unpacked into the custom_nodes directory of ConfyUI:

    ComfyUI/
    └── custom_nodes/
        └── ComfyUI-PainterNodes-MiniMax-Qwen2.1/
          
    Installation Dependency: The original repo recommends soundfile>=0.12.1 and numpy>=1.21.0 which are available in most ComfyUI installations.
